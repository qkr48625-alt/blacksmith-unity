# ⚒️ 대장장이 시뮬레이터 (Unity) — 3D 미니어처 대장간 재설계

> 2026-10-29. [unity-기획-초안.md](unity-기획-초안.md)의 "2D/UI 중심" 방향을 바꾼다.
> 1차 마일스톤은 웹의 게이지 · 버튼 화면을 그대로 옮긴 것이라 Unity를 쓰는 의미가 적었다. 이 문서부터는 **대장간 안에서 손으로 일하는 게임**으로 설계한다.
> 초안의 경영 루프(의뢰 → 재료 → 제작 → 납품 → 성장, §2~§5)는 그대로 가져간다. 바뀌는 것은 **제작을 어떻게 보여 주고 조작하는가**다.

---

## 1. 한 줄 요약

위에서 비스듬히 내려다본 **작은 3D 대장간**에서 대장장이를 움직여 화덕 · 모루 · 물통 · 숫돌 · 작업대를 오가며 쇠를 다룬다. 작업대에 붙으면 카메라가 다가가고, **게이지 대신 손잡이를 끌고, 망치를 내리치고, 크랭크를 돌린다.** 점수는 화면 숫자보다 **쇠의 색 · 모양 · 불티 · 소리**로 먼저 느낀다.

## 2. 웹 버전에서 바꾸는 것

| | 웹 / 1차 마일스톤 | 3D 재설계 |
|---|---|---|
| 화면 | 공정마다 바뀌는 UI 패널 | 대장간 공간 하나. 작업대 사이를 걸어 다님 |
| 공정 진행 | 공정 1 → 2 → 3 순서로 화면이 넘어감 | 작업 지시서(벽 게시판)가 다음 할 일을 알려 주고, **알맞은 작업대로 걸어가서** 시작 |
| 정보 | 온도계 · 힘 게이지 · 점수 숫자 | **쇠가 빛나는 색**(온도), 망치가 올라간 높이(힘), 불티 · 소리 · 화면 흔들림(타격 질). 숫자는 끝나고 검증표에서 |
| 열 | 공정 안에서만(단조 열 관리) | **쇠 한 덩이가 온도를 계속 지닌다.** 모루에서 치다 식으면 직접 들고 화덕으로 가서 다시 달군다 |
| 작업물 | 점수만 쌓이고 마지막에 3D로 봄 | **작업물이 실제로 변한다**: 광석 → 블룸 → 철 바 → 칼날 → 단검. 망치로 친 자리가 실제로 펴진다 |
| 완성품 | 보관함 목록 | **벽 진열대에 걸린다.** 진열대가 곧 보관함 |
| UI | 화면 전체 | 최소한의 HUD(작업 안내, 상호작용 키). 메뉴 · 검증표 · 결과만 UI Toolkit |

**그대로 쓰는 것:** 공정 · 세부 단계 · 가중치 데이터(`ProcessDef` · `RecipeDef`), 점수 합산 · 등급 · 능력치(`Scoring`), 저장(`SaveSystem`), 웹 기획서의 손맛 수치(구간 폭 · 냉각 속도 등)는 튜닝 출발점으로.

## 3. 대장간 공간

```
            [작업 지시서 게시판]         [진열대(완성품)]
   ┌──────────────────────────────────────────────┐
   │  화덕 🔥        모루 🔨          숫돌 ⚙        │
   │  (풀무 손잡이)   (망치 · 집게)     (크랭크 · 물) │
   │                                              │
   │  물통 · 기름통   🧍 대장장이        작업대 🪵    │
   │                                  (손잡이 · 칼집)│
   │  재료 상자                          검사 탁자   │
   └───────────────────[ 문 ]─────────────────────┘
                     (손님 · 시장으로)
```

- **카메라:** 기본은 대장간 전체를 비스듬히(약 50°) 내려다보는 시점. 대장장이를 부드럽게 따라간다.
- **이동:** WASD(또는 왼쪽 스틱) + 바닥 클릭으로 걸어가기. 작업대 앞에서 `E`(또는 작업대 클릭)로 붙는다.
- **작업대에 붙으면:** 카메라가 그 작업대로 다가가 손 작업 시점이 된다(Cinemachine 블렌드). `Esc`/`Q`로 떨어진다.
- **들고 다니기:** 작업물(쇠)은 집게로 들고 다닌다. 들고 있는 동안에도 식는다(빛이 점점 사그라듦).

## 4. 작업대별 조작 (공정 매핑)

웹의 15개 세부 단계를 작업대 동작으로 바꾼다. **같은 손맛(타이밍 · 정확도 · 유지)은 살리되, 정보는 쇠와 도구가 보여 준다.**

### 4-1. 화덕 — 제련 · 가열 (모든 공정이 다시 찾는 곳)
- **풀무질:** 풀무 손잡이를 마우스로 잡고 **아래로 끌어내렸다 놓기**를 되풀이한다. 끄는 빠르기 = 바람. 숯이 밝아지고 불길이 커지며(조명 세기 · 불티 파티클) 노 옆 **놋쇠 다이얼 온도계** 바늘이 움직인다. 금색 구간 머문 시간이 점수(웹 수치 유지).
- **슬래그 배출:** 노 단면이 보이는 구멍으로 녹은 슬래그가 차오른다. 쇠꼬챙이를 끌어 **배출구를 찔러** 뚫는다. 금 · 은 · 동 높이 구간(웹 수치).
- **재가열:** 작업물을 숯 속에 넣으면 온도가 오른다. 색이 체리빛 → 주황 → 노랑으로 변한다. 너무 오래 두면 하얗게 타며 불티가 튄다(과열 감점).

### 4-2. 모루 — 정련 · 칼날 단조 · 마크 · 리벳
- **망치질 공통:** 마우스 버튼을 누르고 있으면 **망치가 위로 올라간다**(높이 = 힘). 떼면 내리친다. 너무 오래 들고 있으면 팔이 떨려 흔들린다(웹의 "다시 빠짐"). 타격 위치는 **마우스가 가리키는 쇠 위의 자리**(레이캐스트).
- **접기 단접(정련):** 정해진 자리(빛나는 표시)를 알맞은 힘으로 4번 치면 쇠가 **실제로 반으로 접히는 애니메이션**. 5번 접기. 접을수록 쇠 표면에 결무늬가 고와진다(셰이더).
- **칼날 형상(단조):** 모루 위 철 바에 **목표 칼날 윤곽이 희미하게** 겹쳐 보인다. 친 자리의 쇠가 **실제로 펴지고 늘어난다**(메시 변형). 점수 = 끝났을 때 윤곽과 맞는 정도. 식으면(빛이 꺼지면) 들고 화덕에 다녀와야 한다 — 웹의 열 관리가 걸어 다니기로 바뀐다.
- **마크 각인:** 펀치를 쇠 위 자리에 대고 망치로 두 번. 마크가 칼날 표면에 **실제로 찍힌다**(데칼).
- **리벳:** 손잡이 조립 후 같은 망치질로 슴베 끝을 퍼뜨린다.

### 4-3. 물통 · 기름통 — 담금질 · 뜨임
- **담금질:** 칼날을 들고 물통 위에서 **색을 보다가 아래로 끌어 담근다.** 김 · 치익 소리 · 물보라. 체리빛에서 담글수록 좋다(색 견본은 물통 옆 벽에 걸린 쇠 조각).
- **뜨임:** 화덕 가장자리에 칼날을 올려 두면 **산화막 색이 칼등에서 날 쪽으로 번진다**(셰이더 그라데이션). 목표색에서 집어 올린다.

### 4-4. 숫돌 — 연마 · 날 세우기
- **숫돌 갈기:** 크랭크 손잡이를 마우스로 **원을 그려 돌린다.** 숫돌이 실제로 돌고, 칼날을 대면 속도만큼 **불티 줄기**와 갈리는 소리. 칼날이 달아오르면 끝이 **푸르게 변색** → 물통 손잡이로 물을 뿌린다.
- **날 세우기:** 손숫돌을 날 선을 따라 끌어 민다. 지나간 자리에 광택이 남는다.

### 4-5. 작업대 — 손잡이 · 칼집
- **그립 구멍:** 송곳을 눌러 박고, 옆으로 흐르는 끝을 마우스로 바로잡는다.
- **조립:** 론델 · 그립 · 폼멜 3D 부품을 **끌어서 슴베에 끼운다**(맞는 방향이면 딸깍 스냅).
- **가죽 성형 · 도장 · 바느질:** 젖은 가죽을 칼날에 문질러 감싸고, 도장을 **3D 칼집 표면에 직접 찍고**(데칼), 바늘을 리듬에 맞춰 꿰맨다.

### 4-6. 검사 탁자 · 진열대
- 완성품을 검사 탁자에 올리면 검사관 검증표(UI)가 뜬다. 등급 · 능력치 · 측정값.
- 진열대 빈 걸이에 걸면 보관함에 들어간다. 진열대에 다가가 하나를 집으면 기록을 다시 본다.

## 5. 피드백 원칙

- **화면 숫자 대신 세계가 반응한다:** 잘 맞으면 맑은 쇳소리 + 큰 불티 + 짧은 화면 흔들림, 빗맞으면 둔한 소리 + 작은 불티.
- **온도는 색으로:** 모든 쇠는 하나의 온도 → 색 규칙(검정 → 체리 → 주황 → 노랑 → 흰색)을 쓴다. 웹의 "색만 보고 판단" 열처리가 게임 전체 규칙이 된다.
- **숫자는 끝에:** 세부 단계가 끝나면 작업대 위에 작은 점수 도장이 떠오르고, 자세한 숫자는 검증표에서.
- **접근성:** 설정에서 "온도 숫자 보기"를 켜면 쇠 옆에 온도가 뜬다(색 구분이 어려운 사람용).

## 6. 기술 구조

| 항목 | 쓰는 것 | 하는 일 |
|---|---|---|
| 렌더 | **URP** + 후처리(Bloom · 비네트 · 색 보정) | 달군 쇠 · 숯이 실제로 빛나 보이게 |
| 카메라 | **Cinemachine** | 전체 시점 ↔ 작업대 시점 블렌드, 타격 때 Impulse 흔들림 |
| 셰이더 | **Shader Graph** | 쇠 온도 발광, 접기 결무늬, 뜨임 산화막 번짐, 연마 광택 · 변색 |
| 효과 | Particle System(필요하면 VFX Graph) | 불티 · 숯불 · 김 · 물보라 · 연마 불꽃 |
| 이동 | **AI Navigation**(NavMesh) | 대장장이 클릭 이동, 나중에 손님 |
| 공간 | **ProBuilder** + 기본 도형 | 대장간 그레이박스 |
| 데칼 | URP Decal Projector | 마크 각인 · 칼집 도장 |
| 입력 | Input System | 마우스 끌기 · 누르고 있기 · 원 그리기, 나중에 패드 |
| 소리 | AudioSource(3D) + Audio Mixer | 작업대 위치에서 소리가 남. 처음엔 짧은 합성음/무료 효과음 |
| UI | UI Toolkit | 메뉴 · 작업 지시서 · 검증표 · 결과 |
| 데이터 · 저장 | 기존 `ProcessDef` · `RecipeDef` · `Scoring` · `SaveSystem` | 재사용 |

### 코드 구조

```
Scripts/Crafting/     (재사용) 공정 · 레시피 · 점수 · 기록
Scripts/Core/         (재사용) 저장 + 작업 흐름(CraftDirector: 지금 할 공정 · 세부 단계, 끝나면 기록)
Scripts/World/        PlayerController · Interactor · Station(작업대 공통) · CameraRig
Scripts/Workpiece/    Workpiece(온도 · 상태 · 모양) · HeatGlow(셰이더 연결) · 상태별 메시
Scripts/Stations/     ForgeStation · AnvilStation · QuenchStation · GrindStation · BenchStation
Scripts/Activities/   세부 단계 동작 하나씩 (Bellows · SlagTap · FoldHammer · ShapeHammer · Quench …)
Scripts/Feedback/     불티 · 소리 · 화면 흔들림 호출 한 곳
Scripts/UI/           HUD · 작업 지시서 · 검증표 · 결과
```

- **Activity 규약:** 지금의 `IMinigame`(시작 · Tick · 점수 + 측정값)을 3D 버전 `IStationActivity`로 바꾼다. UI 요소 대신 작업대 · 작업물 · 카메라를 받는다. 점수 · 측정값 형식은 같아서 `Scoring` · 검증표가 그대로 붙는다.
- **1차 마일스톤 UI 화면(Workshop · Process · Result 화면, Bellows · Fold UI 미니게임)은** 새 구조가 돌아가면 지운다. 그 전까지는 비교용으로 남긴다.

## 8. 2차 마일스톤 — 3D 손맛 검증 (제안)

**목표:** 대장간을 걸어 다니며 화덕과 모루를 오가는 한 바퀴가 재미있는지 확인한다.

1. URP · Cinemachine · Shader Graph · AI Navigation · ProBuilder 넣기, URP 에셋 · 후처리 볼륨 설정
2. 그레이박스 대장간 씬: 바닥 · 벽 · 화덕 · 모루 · 물통 · 작업대 · 진열대, 화덕 불빛 조명
3. 대장장이(캡슐) 이동 · 작업대 상호작용 · 카메라 전환
4. 작업물: 온도 → 발광 셰이더, 식기, 집게로 들고 다니기, 화덕에서 재가열
5. **화덕 풀무질**(손잡이 끌기 + 다이얼 온도계 + 불빛) — 제련 ①
6. **모루 접기 단접**(망치 들기 · 내리치기, 불티 · 소리 · 흔들림, 접히는 애니메이션) — 정련 ①, 식으면 화덕으로
7. 나머지 세부 단계는 해당 작업대에서 임시 점수로 넘어가고, 끝나면 완성 결과(UI) → 진열대에 걸림

이 다음(3차)에 모루 형상 단조(메시 변형) · 담금질 · 숫돌을 넣고, 그 뒤 경영 루프(손님이 문으로 들어오는 의뢰)를 붙인다.

### 8-1. 2차 마일스톤 구현 (2026-10-29)

- **씬:** `Scenes/Workshop.unity`(빌드 첫 씬). 셋업 스크립트(`Blacksmith/Setup Project`)가 없을 때만 짓고, 다시 지으려면 `Blacksmith/Rebuild Workshop Scene`. 1차 UI 화면(`Main.unity`)은 비교용으로 남김.
- **렌더:** URP(`Settings/URP_Pipeline` · `URP_Renderer`), 후처리 볼륨(Bloom · ACES 톤 매핑 · 비네트 · 색 보정). 셰이더 그래프는 아직 안 씀 — 쇠 발광은 Lit 재질의 Emission 색을 온도로 바꾼다.
- **카메라:** Cinemachine 전체 시점(대장장이 따라감, 방향 고정) + 작업대마다 시점 카메라(붙으면 우선순위 20). 망치 타격 때 Impulse 흔들림.
- **이동:** NavMesh(실행할 때 굽기) + WASD · 클릭 · 작업대 클릭 · E.
- **작업물:** `Pieces/Workpiece` — 온도(뉴턴 냉각 · 불 속 가열), 온도 → 발광색, 상태별 기본 도형(블룸 · 철 바 · 칼날 · 단검), 과열 누적.
- **활동:** `Activities/` — 풀무질(`BellowsActivity`, 화덕 손잡이 끌기 · 스페이스), 접기 단접(`FoldActivity`, 망치 들기 · 내리치기 · 눈금 기둥). 나머지 15개 세부 단계는 `PlaceholderActivity`(HUD 점수 고르기). 작업대를 떠나면 멈췄다가 돌아오면 이어 한다.
- **진행:** `WorkshopGame` — 선행 관계(`CraftPlan`), 작업 지시서 HUD, 과열 감점(초당 −4) · 6초 넘으면 버리기, 완성 → 결과 창 → 진열대에 걸림. 저장은 `blacksmith-workshop.json`(1차 UI 와 따로).
- **효과음:** `Feedback/SfxSynth` — 쇳소리(맑음 · 둔함) · 쿵 · 풀무 바람 · 치익 · 타는 소리 · 딸깍을 코드로 합성.
- **아직 없음:** 셰이더 그래프(결무늬 · 뜨임 번짐), 돌발 상황, 15개 세부 단계의 3D 조작, 검사 탁자, 캐릭터 · 소품 에셋.
- **이후 손본 것:** 퀘스트식 안내(지금 할 일 · 가는 곳 · 공정 진행, 가야 할 작업대에 금빛 화살표 · 고리 · 불빛 · 금색 이름표), 작업대에 붙으면 대장장이 숨기기, 가시성(중립 조명 · 회색 바닥 · 푸른 옷 · 가까운 카메라).

### 8-2. 3차 마일스톤 — 세부 단계 3D 조작 (진행 중)

퀘스트 순서대로 임시 점수 단계를 하나씩 바꾼다.

0. **풀무질 손보기** (2026-10-30) — 60초 한 칸 지키기가 지루해서 **30초, 금색 칸(폭 100℃)이 4.5~7초마다 100~200℃씩 옮겨 가는** 방식으로 바꿨다(950~1,300℃ 사이). 옮기기 1초 전에 칸이 깜빡이고 "띵". 옮긴 직후 80℃당 1초는 따라가는 시간이라 칸 밖이어도 감점하지 않는다. 시작 3초도 같다. 온도계 금색 칸은 회전축에 달려 바늘처럼 돌아간다.

2~14. **나머지 13단계** (2026-10-30) — 모두 3D 활동으로 바꿨다. 공통 뼈대는 `Activities/ActivityBase`(소품 뿌리 · 활동 전용 가까운 카메라 · 누름 판정, 떠나면 숨기고 돌아오면 이어 감)와 `ActivityKit`(실행 중에 만드는 기본 도형 소품 · 마우스 조준 · 손 떨림). 소품은 씬에 굽지 않고 활동이 만들었다가 끝나면 지운다. 단계 → 활동은 `ActivityRegistry`가 "공정키.단계키"로 찾는다. 수치는 모두 웹 버전 그대로(화면 단위는 m 로, 열은 실제 온도로).
   - 모루: **재질 분류**(단면을 보고 A/D · 좌/우클릭) · **형상**(떨리는 고리를 날 가장자리 표적에, 칠수록 철 바가 펴짐, 식으면 감점) · **마크 각인**(펀치 두 번, 자국이 작업물에 남음) · **리벳**(접기와 같은 망치질 5번, 슴베 머리가 퍼짐)
   - 화덕: **불림**(누르면 숯 속, 떼면 앞 받침 — 체리빛 견본과 비교, 검게 식은 뒤 다시 3번) · **뜨임**(뜨거운 받침 위에서 산화막 색이 번짐, 금 테 견본 색에서 집기)
   - 물통: **담금질**(김 위에서 식어 가는 칼날을 체리빛일 때 담금, 실제 온도로 판정)
   - 숫돌: **숫돌 갈기**(누른 채 숫돌 둘레로 원 그리기 = 크랭크, 알맞은 속도 · 과열되면 칼날이 푸르게 · 스페이스/우클릭 물) · **날 세우기**(받침대 위 칼날의 금빛 날 선을 따라 손숫돌 밀기, 위아래 번갈아 6번)
   - 작업대: **그립 구멍**(누르면 송곳이 파고들고 옆으로 흐름 — 마우스로 가운데 선 지키기) · **조립**(쟁반에서 집어 R로 뒤집고 슴베에 끼우기) · **가죽 성형**(마르기 전에 윤곽선 문지르기) · **도장**(대칭 · 고른 간격, Enter 로 마침) · **리듬 바느질**(구슬이 금빛 고리에 닿을 때 찌르기/당기기)
   - 퀘스트 안내의 "쇠가 식었어요 → 화덕부터"는 접기 · 형상 · 마크 · 담금질에 붙는다. 작업물이 필요 없는 일을 할 때는 들고 있던 쇠를 작업대 옆에 내려 둔다.
   - **접근성:** T 키로 쇠 온도 숫자 보기(오른쪽 위, 저장됨).
   - 자동 점검(`Blacksmith/Play Smoke Test`)이 모든 활동을 만들어 몇 프레임 돌리고 활동 카메라 사진을 `Logs/smoke-act-*.png` 로 찍는다.
1. **슬래그 배출** (2026-10-30) — `Activities/SlagActivity` + `Stations/SlagPit`. 화덕 앞면 왼쪽에 노 단면 창: 녹은 슬래그 기둥이 차오르고(차오르는 속도 · 출렁임은 웹과 같음), 왼쪽 배출구 · 오른쪽 송풍관 · 가운데 금색 선 · 양옆 틀의 은 · 구리색 눈금. 클릭/스페이스로 쇠꼬챙이를 찔러 뚫으면 배출구에서 줄기가 바닥 홈으로 쏟아진다. 4번, 금 100 · 은 80 · 동 55, 송풍관까지 차면 0점. 하는 동안 창을 가까이 보는 카메라로 넘어가고, 갓 나온 블룸은 숯 속에 묻어 식지 않게 한다.

### 8-3. 4차 마일스톤 — 경영 루프 1차 (2026-10-30)

기획 초안 §2~§5 를 단검 한 레시피로 돌아가게 줄였다. 코드는 `Economy/Economy.cs`(상태 · 규칙 · 값), `World/WorkshopGame.Economy.cs`(하루 · 손님 · 게시판 · 진열대), `World/Customer.cs`(손님 NPC).

- **하루:** 8시~20시. 세부 단계를 끝낼 때마다 대장간 시간이 든다(공정 시간 × 세부 단계 가중치, 단검 한 자루 ≈ 10시간: 제련 2 · 정련 1.5 · 단조 2 · 열처리 1 · 연마 1.5 · 손잡이 1 · 칼집 1). 시간이 모자라면 그 일을 시작할 수 없고, 게시판에서 **하루 마치기** → 저녁 정산(번 돈 · 납품 · 기한 넘긴 의뢰) → 다음 날 아침. 오른쪽 위에 날짜 · 시각 · 돈 · 평판.
- **손님:** 아침마다 2명(평판 10마다 +1, 최대 3명)이 문으로 걸어 들어와 기다린다. 말을 걸면 의뢰 카드 — "단검 · 예리함/강도/장식미/총점 N 이상, M일째 저녁까지, 보수 R실링". 받으면 손님은 나간다. 의뢰는 3건까지. 평판이 오를수록 조건이 높고 보수가 크다(N = 40 + 평판×2 ± , R ≈ 50 + N×1.3).
- **납품:** 게시판 → 의뢰에서 조건에 맞는 완성품을 고른다. 보수 + 조건을 넘긴 만큼 덤, 평판 +2(15 이상 넘기면 +3). 기한을 넘기면 의뢰가 사라지고 평판 −2.
- **판매:** 진열대에서 의뢰에 안 쓴 완성품을 판다. 값 = 20 + 총점×0.9 + (총점−60)×1.2(60 넘는 만큼).
- **재료:** 게시판 → 시장에서 산다. 광석 하 6 · 중 10 · 상 18, 숯 소나무 4 · 참나무 8, 가죽 8 · 고운 가죽 16, 손잡이감 나무 3 · 뼈 8 · 뿔 14. 만들기를 시작할 때 창고에서 하나씩 쓴다. 보정: 하급 광석 = 제련 · 정련 상한 80, 상급 광석 +5, 참나무 숯 = 제련 +3, 고운 가죽 = 칼집 +5, 뼈 = 손잡이 +4, 뿔 = 손잡이 +8. 처음 돈 60실링 + 기본 재료 한 벌.
- **업그레이드:** 큰 풀무(금색 칸 140℃) 120 · 좋은 망치(접기 · 리벳 힘 구간 1.3배) 140 · 단조 집게(형상 · 마크 · 그립 구멍 떨림 0.7배, 평판 3) 160 · 물통 · 기름통(담금질 · 뜨임 · 불림 판정 폭 1.35배, 평판 3) 110 · 고운 숫돌(과열 0.65배, 평판 6) 130. 효과는 `MinigameContext` 보정값으로 활동에 들어간다.
- **퀘스트 창:** 손님이 기다리면 손님에게, 납품할 수 있는 의뢰가 있으면 게시판에 화살표. 받은 의뢰와 남은 날도 보인다.
- **아직 없음:** 레시피 여러 종(장검 · 도끼 · 창촉), 중간 제품 창고 · 한꺼번에 제련, 견습생, 숙련 보너스, 기사단 · 영주 의뢰. 수치는 해 보면서 맞춘다.

## 9. 정한 것 (2026-10-29)

1. **이동:** WASD(카메라 기준 방향) + 바닥 클릭 둘 다. 작업대를 클릭하면 걸어가서 바로 붙는다.
2. **공정 순서 — 자유롭게:** 공정표를 한 줄 순서가 아니라 **선행 관계**로 짠다. 세부 단계마다 "먼저 끝나 있어야 하는 단계"(`requires`)만 정하고, 조건이 풀린 일은 어느 것부터 해도 된다. 재가열은 언제든 된다. 단검의 갈래:
   - 쇠 줄기: 풀무질 → 슬래그 배출 → 접기 단접 → 재질 분류 → 형상 → (마크 각인 · 불림, 순서 자유) → 담금질 → 뜨임 → 숫돌 갈기 → 날 세우기
   - 손잡이: **그립 구멍은 처음부터 언제든**, 조립은 날 세우기 + 그립 구멍 뒤, 리벳은 조립 뒤
   - 칼집: 가죽 성형은 **형상 뒤 언제든**(칼 모양이 나와야 가죽을 맞춘다), 도장 → 바느질
   - 작업 지시서는 "지금 할 수 있는 일"과 어느 작업대인지를 보여 준다.
3. **과열 — 점수 깎다가 오래 가면 버리기:** 철 바 이후의 쇠가 **1,300℃(하얗게 타는 빛)** 를 넘으면 타기 시작한다(흰 불티 · 경고). 탄 시간 1초마다 그때 하고 있던(없으면 다음에 끝내는) 세부 단계 점수 −4. **한 작업물이 모두 6초 넘게 타면 못 쓰게 되어 버린다** — 그 한 자루는 끝나고 처음(제련)부터 다시 만든다. 3초를 넘기면 "곧 못 쓰게 됩니다" 경고.
